# DESCRIPTION 
yt-dlp_CLI is cli tool written in bash that allow cli download with yt-dlp module through url list(s) stored insilde text type file.

## 1. LISTS OF ARGUMENTS
```bash
 --file, -f       : file that contain the lists of urls to download 
 --url, -u        : for single url  download 
 --quality, -q    : for specific quality
 --output, -o     : directory output 

```
